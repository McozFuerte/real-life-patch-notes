# Real-Life Patch Notes

A one-line comedy changelog entry for a bug in human biology, written in terse
engineering release-note register. Entry for the make.fun "Real-Life Patch
Notes: The Comedy Changelog" bounty.

## Run it

```
python3 main.py
```

Writes the patch note to `/output/entry.txt`. Override the output directory with
the `OUTPUT_DIR` environment variable.
